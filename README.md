# pavelkroupa.com

Web Pavla Kroupy. Statické stránky v češtině a angličtině, publikuje je Cloudflare Pages.

| Cesta | Co to je |
|---|---|
| `web/` | celý web: zdroj, build a hotové stránky. Návod je ve [`web/README.md`](web/README.md). |
| `CNAME` | doména pro GitHub Pages. Cloudflare Pages ho nepoužívá. |

Nastavení Cloudflare Pages: production branch `main`, root directory `web`, build output directory `public`, build command prázdný.

Design systém (barvy, písmo, loga, komponenty) je na adrese `/ds`. Stránka není nikde odkazovaná a vyhledávače ji nemají indexovat.
