Design system preview

The rebuild of pavelkroupa.com as a token-driven system — Next.js 15 and Tailwind v4, with every visual value coming from tokens/src. Everything below is rendered from the real components and the real tokens.

The values are placeholders, not the brand. The live site could not be reached from the build environment, so the palette, type ramp and copy are a neutral scaffold standing in until the real ones are available. What is real here is the structure: the token pipeline, the component API and behaviour, and the page layout. Swapping in the brand values is an edit to the token JSON — no component changes.
