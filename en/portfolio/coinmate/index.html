Coinmate · 2023–2026 · Regulated crypto exchange

A design system first, then a new brand identity.

My role External, 2 days a week · led a senior designer and a copywriter

  1. Where it was stuckNo design system
  2. StepA scalable design system
  3. StepOne system for iOS and Android
  4. StepExchanges and banks
  5. ResultA new brand on the same system

Starting point

The company had no design system and no product design team. I built the system first. When the rebrand request came, the exploration took days instead of weeks, and we could test several concepts instead of one.

What I did

A scalable design system. It built on the existing style, so nothing started from scratch. One system for iOS and Android. The mobile apps got the same system, so users recognize the brand everywhere. Exchanges and banks. I analyzed crypto exchanges and banks that are starting to offer crypto. Then I designed the most complex screens for mobile and desktop first, to make sure the system would scale.

Outcome

The design system stayed, and the new brand identity is built on it: a new logo and colors, the same name. I was responsible for the visual design.
